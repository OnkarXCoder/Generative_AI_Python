# Complete Generative AI Course With LangChain and HuggingFace

This repository contains my hands-on practice, notes, and Python code while learning the **Complete Generative AI Course with LangChain and HuggingFace**.

## About This Repo

The goal of this repository is to build a strong foundation in Generative AI by working with Large Language Models (LLMs), prompt engineering, LangChain, HuggingFace, and building real-world AI applications step by step.

## Tech Stack

- **Python** - Core programming language
- **[LangChain](https://www.langchain.com/)** - Framework to build LLM-powered applications
- **[HuggingFace](https://huggingface.co/)** - Open-source models, datasets, and transformers
- **[Transformers](https://huggingface.co/docs/transformers)** - For working with pre-trained LLMs

## Getting Started

1. **Clone the repository**

   ```bash
   git clone https://github.com/OnkarXCoder/Generative_AI_Python.git
   cd Generative_AI_Python
   ```

2. **Create and activate a virtual environment**

   ```bash
   # Windows
   python -m venv venv
   venv\Scripts\activate

   # Linux/Mac
   python3 -m venv venv
   source venv/bin/activate
   ```

3. **Install required packages (as we progress)**

   ```bash
   pip install langchain langchain-huggingface transformers huggingface_hub
   ```

4. **Run any Python file**

   ```bash
   python filename.py
   ```
